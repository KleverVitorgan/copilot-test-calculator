# copilot-test-calculator
Simple Python calculator created with GitHub Copilot

## Features
- Basic arithmetic operations: addition (+), subtraction (-), multiplication (*), and division (/)
- Error handling for division by zero
- Error handling for invalid inputs
- Interactive command-line interface
- Comprehensive unit tests

## Usage

Run the calculator:
```bash
python3 calculator.py
```

Enter calculations in the format: `number operator number`

Examples:
```
10 + 5
20 - 8
6 * 7
15 / 3
```

Type `quit` to exit the calculator.

## Running Tests

Run the unit tests:
```bash
python3 -m unittest test_calculator.py -v
```

## Requirements
- Python 3.x
